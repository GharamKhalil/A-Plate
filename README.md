# A-Plate — النسخة الأصلية مع إصلاحات

تم الاحتفاظ بتصميم الصفحات الخمس الأصلي، مع إصلاح تحديد الصفحة النشطة، وتحسين شريط التنقل للشاشات الصغيرة، وإصلاح مصدر مكتبة الخريطة الحرارية، وإضافة تنزيل CSV فعلي للتقارير.

## التشغيل
افتح `index.html`، أو شغّل المشروع باستخدام Live Server في VS Code. للخرائط والمخططات ستحتاج اتصال إنترنت لتحميل Leaflet وChart.js وFont Awesome.

## مهم
هذه واجهة محاكاة وليست مرتبطة بالجهات الرسمية أو أجهزة مراقبة فعلية. الأرقام والتنبيهات والمواقع نموذجية للتوضيح، وأزرار التحكم لا تتصل بأجهزة حقيقية. لا ترفع بيانات أشخاص أو معلومات حساسة إليها.

## الملفات
- `dashboard.html`: لوحة القيادة
- `alerts_center.html`: التنبيهات
- `analytics_reports.html`: التقارير، تصدير CSV
- `device_details.html`: تفاصيل المركبة
- `field_inspector_mgt.html`: المفتشون
- `assets/fixes.css`: إصلاحات التنقل والتجاوب

## النشر على GitHub Pages
ارفع محتويات هذا المجلد إلى جذر المستودع، ثم Settings → Pages → Deploy from a branch → main / root.


## تحسين الواجهة
تتضمن النسخة ملف `assets/refined.css` الذي يحسّن الخطوط والتباين والبطاقات والتجاوب، مع الحفاظ على صفحات المشروع ومحتواها.
